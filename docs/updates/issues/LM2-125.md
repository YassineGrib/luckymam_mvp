## User Story
> En tant qu'utilisatrice, je veux que la courbe de poids soit lisible jusqu'à 80 kg.

## Description
Adapter l'axe Y (ou le rendre dynamique) pour couvrir au minimum 0–80 kg, sans tronquer les points.  
Option : étendre au-delà si des valeurs > 80 kg existent.

## Critères d'acceptation

```gherkin
Given j'ai des valeurs de poids jusqu'à 80 kg
When j'affiche la courbe
Then toutes les valeurs sont visibles et non tronquées
And l'échelle est correcte jusqu'à 80 kg
```
