## User Story
> En tant que maman, je veux publier un album en ligne pour le partager.

## Description
Publier un album en générant un lien de consultation **read-only**, sécurisé, révocable et expirant.  
Respecter la confidentialité.

## Critères d'acceptation

```gherkin
Given mon album est prêt
When je clique « Publier »
Then un lien unique est généré
And le lien donne accès à l'album en lecture seule
And je peux désactiver le lien (unpublish)
```

## Sécurité
- URL signée + expiration + révocation
- Pas d'indexation par les moteurs de recherche

## Analytics
`album_published` · `album_link_created` · `album_link_revoked`
