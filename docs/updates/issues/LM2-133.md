## User Story
> En tant que maman, je veux accéder à des reels éducatifs spécifiques à un vaccin.

## Description
Ajouter un bouton **« Reels »** sur la fiche vaccin : ouvre le flux reels filtré par tag vaccin.

## Critères d'acceptation

```gherkin
Given je suis sur un vaccin
When je clique « Reels »
Then un flux reels s'ouvre
And le flux est filtré sur ce vaccin
```
