## User Story
> En tant qu'utilisatrice, je veux recevoir des réponses bienveillantes, précises et contextuelles de l'IA Gemini adaptées à l'âge de mes enfants et à ma situation, avec une sécurité médicale stricte en cas de signal d'urgence.

## Description
Intégration du modèle Gemini Flash via une architecture propre et abstraite `AssistantBackend` :
- Interface `AssistantBackend` permettant l'interchangeabilité immédiate entre client direct Flutter, Fake de test, et Cloud Function
- Client Flutter direct utilisant l'API REST Google AI Studio (`gemini-flash-latest`)
- Détection immédiate des signaux d'urgence médicale (Red Flags : saignements abondants, absence de mouvements fœtaux, fièvre nouveau-né) avec orientation directe vers les urgences (14 / 15) sans appel au modèle
- Prompt système bienveillant "Lucky" structuré pour la maternité et la petite enfance
- Gestion robuste des erreurs et indisponibilités réseau avec messages localisés conviviaux

## Critères d'acceptation
```gherkin
Scenario: Alerte médicale rouge
  Given une question mentionnant un saignement ou une fièvre de nouveau-né
  When le message est analysé
  Then le système retourne immédiatement un message d'orientation médicale d'urgence
  And aucun appel externe vers le modèle n'est effectué

Scenario: Réponses adaptées au contexte
  Given une question de l'utilisatrice
  When Gemini répond
  Then la réponse est formulée dans la langue de l'application (AR/FR)
```
