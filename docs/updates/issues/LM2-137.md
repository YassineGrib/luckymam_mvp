## User Story
> En tant que maman, je veux commander l'impression d'un album (prédéfini ou standard).

## Description
Depuis un album (prédéfini ou standard), accès direct au flow album papier :
1. Prévisualisation PDF
2. Commande d'impression

## Critères d'acceptation

```gherkin
Given je suis dans un album (prédéfini ou standard)
When je clique « Commander »
Then je passe par la prévisualisation PDF
And je peux finaliser une commande d'impression
```
