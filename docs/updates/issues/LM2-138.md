## User Story
> En tant qu'utilisatrice, je veux découvrir les produits des partenaires sur un marketplace.

## Description
Créer une page **Marketplace** avec :
- Listing produits (image, titre, prix, partenaire)
- Page détail produit
- CTA « Commander »

## Critères d'acceptation

```gherkin
Given j'ouvre « Marketplace »
Then je vois une liste de produits partenaires

When je clique sur un produit
Then j'ouvre la fiche produit avec détails et CTA « Commander »
```
