## User Story
> En tant qu'utilisatrice, je veux accéder rapidement aux réglages de notifications.

## Description
Ajouter un raccourci vers les préférences notifications (catégories + quiet hours).

## Critères d'acceptation

```gherkin
Given je suis sur Home (ou Settings)
When je clique sur « Raccourcis notifications »
Then j'ouvre l'écran de préférences notifications
And je peux activer/désactiver des catégories
```

## Sécurité
- Opt-in push requis
- Stockage sécurisé des préférences

## Analytics
`notif_shortcut_opened` · `notif_prefs_updated`
