## User Story
> En tant que maman, je veux programmer un rappel pour un jalon.

## Description
Ajouter un bouton **« Rappel »** sur un jalon : planification notification + deep link vers le jalon + options snooze.

## Critères d'acceptation

```gherkin
Scenario: Programmation
  Given je suis sur un jalon
  When je clique « Rappel » et je choisis une date/heure
  Then un rappel est enregistré
  And je reçois la notification à l'heure prévue (si opt-in)

Scenario: Deep link
  Given je tape sur la notification
  Then l'app ouvre directement le jalon concerné
```

## Sécurité
- Rate limiting
- Validation des deep links
- Opt-in requis
