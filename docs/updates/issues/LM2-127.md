## User Story
> En tant que maman, je veux pouvoir créer une capsule émotionnelle pour chaque jalon.

## Description
Chaque jalon doit proposer « Créer capsule » (ou « Voir capsule » si existante) et permettre l'association capsule ↔ jalon.

## Critères d'acceptation

```gherkin
Given je consulte un jalon (quel qu'il soit)
Then je vois l'action « Créer une capsule »
And après création, je peux ouvrir la capsule depuis ce jalon
```
