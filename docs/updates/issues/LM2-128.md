## User Story
> En tant que maman, je veux ajouter rapidement une capsule ou un jalon depuis la timeline.

## Description
Ajouter un bouton **« + »** sur la timeline qui ouvre un menu :
1. Créer capsule maintenant
2. Ajouter jalon personnalisé

## Critères d'acceptation

```gherkin
Given je suis sur la Timeline
When je clique sur « + »
Then je vois au moins 2 actions: « Créer capsule » et « Ajouter jalon »
```
