## User Story
> En tant qu'utilisatrice, je veux voir le nom de la marque écrit correctement partout.

## Description
Remplacer toutes les occurrences UI **« LuckyMam »** → **« Luckymam »** (strings, titres, headers, etc.).

## Critères d'acceptation

```gherkin
Given je navigue sur les écrans principaux
Then aucune occurrence « LuckyMam » n'est visible
And « Luckymam » est affiché partout à la place
```
