## User Story
> En tant qu'utilisatrice, je veux accepter la Loi 18/07 afin de valider ma demande/inscription.

## Description
Afficher le texte légal Loi 18/07 et une case obligatoire « J'accepte ».  
Sauvegarder la preuve de consentement : `consent=true/false`, horodatage, version du texte.

## Critères d'acceptation

```gherkin
Scenario: Blocage sans acceptation
  Given je suis sur l'écran contenant le texte Loi 18/07
  When je tente de continuer sans cocher « J'accepte »
  Then la progression est bloquée
  And un message clair indique que l'acceptation est obligatoire

Scenario: Consentement sauvegardé
  Given je coche « J'accepte »
  When je clique sur « Continuer »
  Then la progression est autorisée
  And le système sauvegarde consent=true, timestamp, version_texte
```

## Sécurité
- Preuve de consentement horodatée
- Protection anti-altération côté serveur (audit log / hash)
