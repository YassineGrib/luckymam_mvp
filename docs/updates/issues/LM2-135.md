## User Story
> En tant que maman, je veux un album vide à remplir librement avec mes capsules.

## Description
Créer un modèle standard (pages/slots vides) avec ajout de capsules/photos et sauvegarde en brouillon.

## Critères d'acceptation

```gherkin
Given je choisis « Album standard »
When j'ajoute une capsule dans un slot
Then le slot affiche la capsule
And l'album conserve l'état (brouillon) si je quitte
```
