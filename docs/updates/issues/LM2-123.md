## User Story
> En tant qu'utilisatrice, je veux indiquer que je souhaite être enceinte (HOPE).

## Description
Ajouter un statut profil **« HOPE »** (souhaite être enceinte) en plus de « MAMAN » et « ENCEINTE ».  
Impact UI : pas de bloc grossesse (DPA/semaines) si statut = HOPE.

## Critères d'acceptation

```gherkin
Given je suis dans l'écran profil
When je sélectionne le statut « HOPE »
Then le statut est sauvegardé
And les écrans liés à la grossesse (DPA/semaines) ne s'affichent pas
```

## Sécurité
- Chiffrement au repos + minimisation
- Contrôle d'accès
