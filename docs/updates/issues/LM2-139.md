## User Story
> En tant qu'utilisatrice, je veux commander un produit partenaire depuis l'app.

## Description
Panier + adresse + confirmation commande (paiement optionnel V1).  
Prévoir statuts commande et historique.

## Critères d'acceptation

```gherkin
Scenario: Passage de commande
  Given je suis sur une fiche produit
  When je clique « Commander » et je renseigne les informations requises
  Then une commande est créée
  And je vois un écran de confirmation

Scenario: Historique
  Given j'ai passé une commande
  When j'ouvre « Mes commandes »
  Then je vois la commande et son statut
```
