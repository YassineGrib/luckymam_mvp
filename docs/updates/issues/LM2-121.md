## User Story
> En tant qu'utilisatrice, je veux une photo de profil plus visible sur la Home.

## Description
Agrandir la taille de l'avatar sur Home (responsive, touch target conforme).

## Critères d'acceptation

```gherkin
Given je suis sur la Home
Then l'avatar est plus grand qu'avant
And la mise en page reste stable sur petits écrans
And l'avatar reste cliquable (touch target conforme)
```

## Notes d'implémentation
- Touch target minimum recommandé : 48×48 dp
- Tester sur petits écrans (360dp de large)
