## User Story
> En tant qu'utilisatrice, je veux voir le logo et le nom Luckymam à l'ouverture de l'app.

## Description
Sur l'écran d'entrée (splash), afficher le logo existant + le texte « Luckymam » (orthographe exacte). Support RTL.

## Critères d'acceptation

```gherkin
Given j'ouvre l'application
When l'écran splash s'affiche
Then le logo Luckymam est visible
And le texte « Luckymam » est visible et lisible
And l'affichage fonctionne en RTL (arabe)
```
