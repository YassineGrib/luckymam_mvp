## User Story
> En tant que maman, je veux un album prédéfini basé sur des évènements, en attachant mes capsules.

## Description
Créer des modèles prédéfinis d'album avec une liste d'évènements.  
Chaque évènement peut être rempli via :
- Sélection d'une capsule existante
- Création d'une nouvelle capsule liée

## Critères d'acceptation

```gherkin
Given je choisis « Album prédéfini »
When je sélectionne un évènement
Then je peux attacher une capsule existante
Or je peux créer une nouvelle capsule liée à l'évènement
```
