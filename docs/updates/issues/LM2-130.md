## User Story
> En tant que maman, je veux obtenir des conseils pour comprendre le jalon et réussir ma photo.

## Description
Ajouter un bouton **« Conseil »** sur le détail d'un jalon : ouvre une fiche avec explication + suggestions de positions photo.  
Contenu statique en V1.

## Critères d'acceptation

```gherkin
Given je suis sur un jalon
When je clique « Conseil »
Then une page/modale s'ouvre avec explication du jalon
And une section propose des conseils photo
```
