## User Story
> En tant que maman, je veux voir la miniature de ma capsule sur le jalon.

## Description
Après enregistrement d'une capsule, afficher la vignette (thumbnail) sur la carte du jalon + refresh immédiat.

## Critères d'acceptation

```gherkin
Given j'ai créé une capsule pour un jalon
When je reviens sur la timeline
Then la carte du jalon affiche la vignette de la capsule
```
