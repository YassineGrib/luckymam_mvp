سجل التعديلات الـ 36 حسب الفئات الوظيفية

تم تصنيف التحسينات عبر 8 محاور تطويرية شملت الهوية اللفظية، تجربة التسجيل، السياسة السعرية، والشاشات الحيوية:

الفئة المحور وعدد التعديلات طبيعة التعديل المنجز الأثر على تجربة المستخدم
فئة ١ المحتوى والنصوص (6 تعديلات) اعتماد الشعار الرسمي الموحد: «ذكريات تُروى، ومشاعر تُستعاد». استبدال الكلمات الجافة بعبارات مريحة (مثلاً: استبدال شارة «متأخر» بعبارة «في انتظار التوثيق» واستبدال «اللقاحات» بـ «صحة الطفل»). أسلوب إيجابي ومحفز للأم وخالٍ من لوم التأخير.
فئة ٢ المصادقة والجانب القانوني (3 تعديلات) إدراج خانة الموافقة الصريحة في شاشة التسجيل، إنشاء شاشة مستقلة لسياسة الخصوصية وحماية البيانات، وتثبيت المظهر الفاتح كوضع افتراضي للتطبيق. وضوح قانوني كامل وواجهة مشرقة ومريحة للعين.
فئة ٣ الأسعار والاشتراكات (5 تعديلات) توحيد قائمة الأسعار: الاشتراك المميز (Premium) بـ 2,490 دج/سنوياً واشتراك كبار الشخصيات (VIP) بـ 9,890 دج/سنوياً (يشمل بطاقة العضوية وألبوم صور مطبوع)، مع صفحة الشركاء المتميزين. وضوح العروض التجارية وتعزيز قيمة باقة VIP.
فئة ٤ الشاشة الرئيسية وملف الطفل (4 تعديلات) تصميم جديد للوصول السريع بنسق 4×1 بخلفية كاملة. إنشاء شاشة خاصة لكل طفل تحتوي على بطاقة رأسية ملونة حسب جنس الطفل، 3 بطاقات إحصائية، شبكة ذكريات 3×3 وسجل اللقاحات الكامل. الوصول السريع لكافة تفاصيل كل طفل بنقرة واحدة.
فئة ٥ الخط الزمني (Timeline) (9 تعديلات) إصلاح مسار الرجوع، تفعيل التمرير المزدوج الأفقي والعمودي، ظهور شعار لاكي مام على نقاط المحطات، وحفظ التاريخ الفعلي للحدث في فايرستور. سلاسة تامة في استعراض تاريخ نمو الطفل.
فئة ٦ كبسولات الذكريات (3 تعديلات) وضع علامة مائية هادئة على الصور، أداة اختيار تاريخ التقاط الصورة الفعلي، وتصنيف الذكريات عبر 5 مراحل حياتية. أرشفة زمنية دقيقة ومرتبة للحظات العائلية.
فئة ٧ الصحة واللقاحات (تعديلان) إدراج تقويم لاختيار تاريخ أخذ اللقاح، وإرفاق صفحات تعريفية طبية لكل لقاح (الهدف منه، طريقة الحقن، والأعراض المتوقعة). دفتر صحي وقائي وتثقيفي متكامل للأم.
فئة ٨ الفيديوهات التربوية (Reels) (تعديل واحد) تنسيق مكتبة الفيديو وربط المقاطع التوعوية بفئات الأعمار واللقاحات المناسبة. محتوى طبي موثوق ومبسط للأمهات.

الترقية التفاعلية للكبسولات الصوتية (03 مارس 2026)

لتحويل لحظة فتح الكبسولة إلى تجربة شعورية حية ومؤثرة، تم تجديد مشغل الوسائط بالكامل ليعمل بالوضع الغامر:

الوضع الحي الغامر (Live Mode) تركيز بصري كامل

بمجرد أن تبدأ الأم في الاستماع إلى التسجيل الصوتي للكبسولة، تختفي تلقائياً وبنعومة جميع النصوص والأزرار وأشرطة العناوين، لتملأ صورة الطفل كامل مساحة الشاشة. نقرة خفيفة واحدة على الشاشة تعيد عناصر التحكم فوراً.

حركة كين بيرنز الهادئة (Ken Burns) حيوية المشهد

أثناء استماع الأم لصوت طفلها أو مشاعرها المسجلة، تتحرك الصورة ببطء وانسيابية فائقة عبر تقريب هادئ وتدريجي يضفي الحياة على الصورة الثابتة دون أي اهتزاز أو تشويش.

تخصيص المشغل بشعار لاكي مام الرسمي هوية بصرية متقنة

تم استبدال زر التشغيل التقليدي بميدالية محفورة تحمل شعار لاكي مام الرسمي بدقة المتجهات (SVG)، حيث يتواصل مشغل الصوت CapsuleAudioPlayer مباشرة مع الشاشة الرئيسية لإدارة توقيت تلاشي الواجهة.

التوقيع الرقمي للإنتاج وتكامل تسجيل جوجل

للانتقال من مرحلة التطوير إلى متجر التطبيقات الرسمي، تم قفل سلسلة بناء النسخة وتأمين مفاتيح التشفير الرسمية:

android/app/build.gradle.kts · إعدادات التوقيع الرقمي 
// عزل مفاتيح التوقيع وحمايتها لبيئة الإنتاج
signingConfigs {
    create("release") {
        keyAlias = keystoreProperties["keyAlias"] as String
        keyPassword = keystoreProperties["keyPassword"] as String
        storeFile = file(keystoreProperties["storeFile"] as String)
        storePassword = keystoreProperties["storePassword"] as String
    }
}
buildTypes {
    getByName("release") {
        signingConfig = signingConfigs.getByName("release")
        isMinifyEnabled = true
        proguardFiles(getDefaultProguardFile("proguard-android-optimize.txt"), "proguard-rules.pro")
    }
}
حل مشكلة تسجيل الدخول عبر جوجل في نسخة الإنتاج

تسبب اختلاف التوقيع بين نسختي التطوير والإنتاج سابقاً في توقف تسجيل الدخول عبر حسابات جوجل. تم استخراج بصمة SHA-1 الرسمية للإنتاج (2E:AD:C4:88:...) من المفتاح المحمي Luckymam-release.jks وتسجيلها في خوادم فايربيز، مما أمّن تسجيل الدخول بسلاسة وسرعة فائقة.
