الحماية القانونية والخصوصية الفصل الثالث

الامتثال القانوني (القانون 18-07) ودعم اللغات

يتعامل تطبيق لاكي مام مع بيانات صحية حساسة للغاية تخص الحمل وفترات الرضاعة وصور الأطفال القُصّر. وانطلاقاً من ذلك، طُبقت أعلى المعايير القانونية المتوافقة مع التشريع الجزائري، وتم بناء سجل إثبات غير قابل للتزوير مدعوم ببصمة تشفيرية رياضية، بالتوازي مع دعم كامل ومتقن للغة العربية باتجاه اليمين (RTL).

١. الإطار التشريعي للقانون الجزائري رقم 18-07

يحدد القانون رقم 18-07 المؤرخ في 10 يونيو 2018 القواعد الصارمة لحماية الأشخاص الطبيعيين في مجال معالجة المعطيات ذات الطابع الشخصي في الجزائر، ويفرض:

الموافقة الصريحة المسبقة

حظر جمع أو معالجة أي بيانات تخص المستخدمة أو أطفالها دون إقرار خطي رقمي صريح ومسبق ومستنير.

خصوصية المعطيات الصحية

فرض حماية مضاعفة على تواريخ التلقيح، نمو الأجنة، وتطور الوزن، مع منع مشاركتها قطعياً مع أي أطراف تجارية.

حق التعديل والنسيان

تمكين الوالدين في أي لحظة من تصدير سجلاتهم العائلية، تعديلها، أو طلب الحذف النهائي والشامل من الخوادم.

٢. شاشة الموافقة الإلزامية وهندسة التفاعل اللمسي

لضمان الحجية القانونية الكاملة، لا تقتصر الموافقة على سطر صغير في أسفل الشاشة، بل تفرض واجهة حصرية مخصصة:

شاشة الموافقة الحصرية (Law1807ConsentScreen) مرور إجباري

يتم اعتراض أي حساب يتم إنشاؤه عبر البريد أو تسجيل جوجل بواسطة موجه المسارات app_router.dart. ويبقى الوصول إلى الشاشة الرئيسية /home مقفلاً بالكامل حتى تأكيد الموافقة.

  • عرض النص القانوني الكامل باللغة المحددة للمستخدمة (عربي، فرنسي، إنجليزي).
  • خانة اختيار لمسية بارتفاع مريح (48 بكسل على الأقل) تقع في منطقة الإبهام الطبيعية.
  • تسجيل فوري لحدث law1807_blocked في حال محاولة تجاوز الشاشة دون موافقة.
تسوية الحسابات المسجلة سابقاً أثر رجعي فوري

عند إطلاق التحديث v1.1.0، تم توجيه كافة الحسابات النشطة القديمة التي لم توثق موافقتها قانونياً بشكل آلي نحو شاشة الموافقة، مما حقق نسبة امتثال بلغت 100% لكامل قاعدة المستخدمات.

٣. سجل الإثبات غير القابل للتعديل وبصمة FNV-1a الرياضية

عند قيام المستخدمة بالموافقة، يتولى المحرك ComplianceService إنشاء وثيقة إثبات مشفرة تُحفظ في قاعدة البيانات:

هيكل وثيقة الإثبات في قاعدة البيانات · /consent_logs/{logId} 
{
  "userId": "bsOKvrjp5yM1JEsHZ19TeEHPw1h2",
  "consentGiven": true,
  "timestamp": "2026-06-16T10:14:22.845Z",
  "lawVersion": "18-07_v1.0",
  "language": "ar",
  "ipAddress": "197.200.xx.xx",
  "integrityHash": "b78f4a12c8e901f4", // بصمة رياضية محكمة بنظام FNV-1a 64-bit
  "immutableAudit": true
}
حماية النزاهة ببصمة FNV-1a 64-bit التشفيرية

تُحسب البصمة integrityHash عبر دمج معرف المستخدم، التوقيت بالمللي ثانية، كود اللغة، والنص الكامل للبنود القانونية. إذا حاول أي طرف تعديل أي حرف داخل قاعدة البيانات لاحقاً، فإن إعادة فحص البصمة الرياضية ستكشف التزوير فوراً أمام لجان التدقيق القضائية.

القفل السحابي لمنع التعديل والحذف (firestore.rules)

تم نشر القواعد السحابية لضمان مناعة مطلقة لسجل الموافقات: 

// قفل سجلات التدقيق القانونية ومنع التعديل أو الحذف نهائياً
match /consent_logs/{logId} {
  allow create: if request.auth != null;
  allow read: if request.auth != null && (request.auth.uid == resource.data.userId || request.auth.token.admin == true);
  allow update: if false; // ممنوع منعاً باتاً: لا تعديل إطلاقاً
  allow delete: if false; // ممنوع منعاً باتاً: لا حذف إطلاقاً
}

٤. نظام اللغات الثلاث والاتجاه العربي من اليمين لليسار (RTL)

احتراماً للهوية الجزائرية، يقدم التطبيق دعماً أصيلاً للغة العربية مع التكيف الهندسي التام لاتجاه الواجهات:

اللغة العربية الرسمية
انعكاس الواجهة التام (RTL)

تتحول محاذاة القوائم، الأشرطة الجانبية، أشرطة التقدم، والرموز والأسهم تلقائياً لتناسب طبيعة القراءة العربية بكل راحة وتناسق.

اللغة الفرنسية
المصطلحات الطبية الدقيقة

صياغة طبية احترافية توافق المصطلحات الطبية المتداولة في دفاتر الصحة المعتمدة.

اللغة الإنجليزية
المعايير الدولية

تغطية كاملة للمقيمين وتوافق مع متطلبات النشر والوصول العالمية.

التبديل الفوري للغة عبر Riverpod

تغيير اللغة من شاشة الملف الشخصي يستدعي الإجراء localeProvider.setLocale()، حيث يتم تحميل ملفات .arb وتحديث كافة شاشات التطبيق في أجزاء من الثانية دون أي وميض أو انقطاع في الجلسة.
